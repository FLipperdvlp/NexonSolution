# 🍓 Nexon Reputation Bot

> Telegram-бот для проверки репутации продавцов, сбора отзывов и безопасных сделок с внутренним балансом на USDT (TRC20).

Разработан командой **NEXON SOLUTION GROUP**.

---

## 📖 О проекте

Если ты хоть раз покупал что-то у незнакомого продавца в Telegram-чате — ты знаешь это чувство: «а вдруг кинут?». **Nexon Reputation Bot** решает эту проблему.

Бот превращает любой Telegram-чат или канал в мини-биржу репутации: пользователи оставляют друг другу отзывы прямо в переписке (`+реп` / `-реп`), бот считает рейтинг доверия, banит мошенников и умеет мониторить целые каналы, автоматически собирая оттуда отзывы. Плюс — встроенный кошелёк с депозитами и выводом через **@CryptoBot**, чтобы можно было проводить сделки безопасно, не покидая Telegram.

Никаких сторонних сайтов, никаких «покажи скрин из другого бота» — всё в одном месте.

## ✨ Возможности

- **✍️ Отзывы в один клик** — пошаговый мастер (`/rep`) или классическая текстовая команда `+реп @user описание` прямо в группе, со скриншотом сделки в подтверждение
- **🔍 Проверка репутации** — команда `/check`, кнопка в меню или reply на сообщение продавца; карточка с рейтингом, историей сделок и скринами
- **📊 Топ продавцов** — рейтинг лучших по количеству и качеству отзывов
- **📡 Мониторинг каналов** — бот сам собирает отзывы из подключённых каналов, без участия модераторов
- **🎨 Уровни доверия** — от 🟢 «Проверенный» до 🔴 «Мошенник», с наглядной шкалой
- **💳 Внутренний баланс** — пополнение и вывод USDT (сеть TRC20) через @CryptoBot, переводы между пользователями
- **🛡️ Гарант сделок** — живой гарант или автоматический депозит-гарант для крупных сделок
- **🚫 Антиспам и модерация** — бан/разбан, удаление отзывов, защита от накрутки, блокировка команд от не-админов в чужих группах
- **🛡️ Админ-панель** — управление пользователями и отзывами без доступа к базе напрямую
- **📝 Логирование действий** — отдельный ротируемый лог всех значимых событий (`actions.log`) для аудита

## 🛠️ Технологии

| Категория | Технология |
|---|---|
| Язык | Python 3.11+ |
| Telegram Bot Framework | [aiogram 3.x](https://docs.aiogram.dev/) (async) |
| FSM / состояния диалогов | aiogram FSM + `MemoryStorage` |
| База данных | SQLite (собственный слой `db.database.Database`) |
| Платежи / вывод средств | [@CryptoBot API](https://help.crypt.bot/crypto-pay-api) через `aiocryptopay` |
| Веб-сервер (webhook/webapp) | `aiohttp` |
| Логирование | `logging`, `TimedRotatingFileHandler`, `concurrent-log-handler` |
| Конфигурация | `python-dotenv` (`.env`) |

## 🏗️ Архитектура проекта

```
NexonSolution/
├── core.py                 # единая точка инициализации: bot, dp, db, crypto, состояния FSM
├── Main_bot_code.py         # точка входа: регистрация хендлеров, запуск polling
├── handler/
│   ├── handler.py           # основные хендлеры (меню, команды)
│   ├── wallet.py             # баланс, депозиты, вывод средств
│   └── withdrawals.py        # обработка заявок на вывод
├── keyboards/                # инлайн-клавиатуры (меню, гарант, отзывы и т.д.)
├── checks/                    # валидация (адреса TRC20, проверки прав)
├── classes/                   # состояния FSM и вспомогательные классы
├── db/
│   └── database.py            # слой работы с SQLite
└── logs/                      # ротируемые логи бота и действий пользователей
```

Ключевой принцип архитектуры: **все общие объекты (`bot`, `dp`, `db`, `crypto`) создаются один раз в `core.py`** и импортируются во все остальные модули — это исключает дублирование инстансов и циклические импорты между `Main_bot_code.py` и хендлерами.

## 🚀 Установка и запуск

1. **Клонируй репозиторий**

   ```bash
   git clone https://github.com/your-org/nexon-reputation-bot.git
   cd nexon-reputation-bot
   ```

2. **Установи зависимости**

   ```bash
   pip install -r requirements.txt
   ```

3. **Создай `.env` файл** в корне проекта:

   ```env
   BOT_TOKEN=твой_токен_из_BotFather
   CRYPTO_TOKEN=твой_токен_из_CryptoBot
   DB_PATH=reputation.db
   LOGS_DIR=logs
   GARANT_USERNAME=username_гаранта
   ```

   > ⚠️ Никогда не коммить `.env` и не хардкодить токены в коде — добавь `.env` в `.gitignore`.

4. **Запусти бота**

   ```bash
   python Main_bot_code.py
   ```

## 💬 Основные команды

| Команда | Описание |
|---|---|
| `/start` | Главное меню |
| `/rep` | Оставить отзыв (пошаговый мастер) |
| `/check @username` | Проверить репутацию продавца |
| `/help` | Инструкция по использованию |
| `+реп @user текст` | Быстрый положительный отзыв (текстом в чате) |
| `-реп @user текст` | Быстрый отрицательный отзыв |
| `/admin` | Админ-панель (только для админов) |
